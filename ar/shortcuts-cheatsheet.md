# ورقة غش اختصارات Burp Suite (Keyboard Shortcuts Cheat Sheet)

> 🌐 **اللغة / Language:** [English Version (`en/shortcuts-cheatsheet.md`)](../en/shortcuts-cheatsheet.md)

---

## 🎯 الهدف من الدليل

توفير مرجع فوري وشامل لأهم **اختصارات لوحة المفاتيح (Hotkeys)** داخل أداة Burp Suite لأنظمة **Windows / Linux** و **macOS**. إتقان هذه الاختصارات يضاعف سرعة تحليلك اليدوي ويغنيك عن إضاعة الوقت في فتح القوائم بالماوس أثناء سيناريوهات اختبار الاختراق ومسابقات الـ CTF.

---

## 🚀 1. التوجيه والإرسال السريع بين الأدوات (Cross-Tool Routing)

هذه الاختصارات تعمل في أي مكان داخل Burp (سواء كنت في سجل الـ Proxy، أو أداة Scanner، أو Logger):

| الوظيفة / الإجراء | Windows / Linux | macOS | ملاحظات واستخدامات |
| :--- | :---: | :---: | :--- |
| **إرسال الطلب إلى Repeater** | `Ctrl + R` | `⌘ + R` | الاختصار الأكثر استخداماً لعزل الطلب وبدء تحليله يدوياً. |
| **إرسال الطلب إلى Intruder** | `Ctrl + I` | `⌘ + I` | لنقل الطلب مباشرة لبدء هجمات التخمين والـ Fuzzing. |
| **أرشفة الطلب في Organizer** | `Ctrl + O` | `⌘ + O` | لتجميد وحفظ دليل استغلال الثغرة (PoC) فور اكتشافها. |
| **إرسال الطلب إلى Sequencer** | `Ctrl + S` | `⌘ + S` | لنقل الطلب فوراً لاختبار عشوائية التوكنات (Entropy). |
| **التبديل بين التابات المجاورة** | `Ctrl + Tab` | `Ctrl + Tab` | للتنقل السريع بين تابات Repeater أو Intruder المفتوحة. |
| **إغلاق التاب الحالي** | `Ctrl + W` | `⌘ + W` | لإغلاق تاب الـ Repeater النشط. |

---

## 🛡️ 2. التحكم في البروكسي واعتراض الطلبات (Proxy Interception)

تُستخدم داخل تاب `Proxy > Intercept` لإدارة حركة المرور المتوقفة:

| الوظيفة / الإجراء | Windows / Linux | macOS | ملاحظات واستخدامات |
| :--- | :---: | :---: | :--- |
| **تمرير الطلب المحتجز (Forward)** | `Ctrl + F` | `⌘ + F` | إرسال الطلب المعترض إلى السيرفر فوراً. |
| **إسقاط الطلب المحتجز (Drop)** | `Ctrl + D` | `⌘ + D` | إلغاء الطلب نهائياً ومنعه من الوصول للسيرفر. |
| **تفعيل / تعطيل Intercept** | `Ctrl + T` | `⌘ + T` | مفتاح تبديل فوري لتشغيل وإيقاف اعتراض الطلبات. |

---

## ⚡ 3. أداة Repeater وإرسال الطلبات (Repeater Execution)

| الوظيفة / الإجراء | Windows / Linux | macOS | ملاحظات واستخدامات |
| :--- | :---: | :---: | :--- |
| **إرسال الطلب (Send Request)** | `Ctrl + Space` | `⌘ + Space` | إرسال الطلب ومراقبة الرد دون الحاجة للنقر على زر Send بالماوس. |
| **إلغاء الطلب المعلق (Cancel)** | `Esc` أو `Ctrl + C` | `Esc` | لإيقاف الاتصال إذا كان السيرفر يستغرق وقتاً طويلاً (Time-out). |
| **فتح تاب جديد فارغ** | `Ctrl + N` | `⌘ + N` | لإنشاء طلب يدوي جديد من الصفر. |
| **مضاعفة التاب الحالي (Duplicate)** | `Ctrl + Shift + D` | `⌘ + Shift + D` | مفيد جداً لنسخ طلبات Race Conditions قبل تجميعها في Group. |
| **التنقل في تاريخ الطلب (History)** | `Ctrl + [` / `Ctrl + ]` | `⌘ + [` / `⌘ + ]` | للتنقل بين التعديلات السابقة واللاحقة لنفس التاب في Repeater. |

## 🔤 4. الترميز وفك الترميز السريع (Inline Encoding & Decoding)

تعمل هذه الاختصارات بمجرد تحديد (Highlight) أي نص أو كلمة داخل نافذة تحرير الطلب:

| نوع التحويل / التشفير | Windows / Linux | macOS | مثال للتحويل |
| :--- | :---: | :---: | :--- |
| **URL-Encode (Key Characters)** | `Ctrl + U` | `⌘ + U` | يحول المسافات والرموز: `admin 1` ← `admin+1` أو `%20` |
| **URL-Decode** | `Ctrl + Shift + U` | `⌘ + Shift + U` | يفك ترميز: `%27%20OR%201=1` ← `' OR 1=1` |
| **HTML-Encode** | `Ctrl + H` | `⌘ + H` | يحول وسوم الـ XSS: `<script>` ← `&lt;script&gt;` |
| **HTML-Decode** | `Ctrl + Shift + H` | `⌘ + Shift + H` | يفك ترميز الكيانات الخاصة بالـ HTML. |
| **Base64-Encode** | `Ctrl + B` | `⌘ + B` | تشفير فوري: `admin:admin` ← `YWRtaW46YWRtaW4=` |
| **Base64-Decode** | `Ctrl + Shift + B` | `⌘ + Shift + B` | فك تشفير توكنات وباراميترات الـ Base64 على الطاير. |

| الوظيفة / الإجراء | Windows / Linux | macOS |
| :--- | :---: | :---: |

| **إعادة التعديل (Redo)** | `Ctrl + Y` | `⌘ + Y` |

## ⚙️ 6. كيفية تخصيص وتعديل الاختصارات (Customizing Hotkeys)

إذا تعارض أي اختصار مع اختصارات نظام التشغيل لديك، يمكنك تغييره بسهولة عبر الخطوات التالية:

1. من القائمة العلوية، اذهب إلى: **Settings > User interface > Hotkeys**.
2. ستجد جدولاً بكافة الإجراءات المتاحة داخل Burp Suite.
3. انقر مرتين على أي اختصار، واضغط على الأزرار الجديدة التي تريد تعيينها من لوحة المفاتيح.
4. اضغط **Apply** لحفظ التخصيص فوراً.

> [!TIP]
> **نصيحة للمحترفين:** عين اختصاراً مخصصاً لـ `Proxy: Toggle intercept on/off` (مثل مفتاح `F8` أو `Pause/Break`) لتمكين وإيقاف اعتراض الطلبات بنقرة زر واحدة أثناء تصفح الموقع بالمتصفح!
