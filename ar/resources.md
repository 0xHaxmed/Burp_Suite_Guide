## 🎯 الهدف من الملحق

توفير قائمة شاملة ومنتقاة بعناية لأهم المراجع الأكاديمية والعملية، والشهادات المهنية المعتمدة عالمياً، ومنصات التدريب المجانية، والمستودعات البرمجية المساعدة لمواصلة رحلة الاحتراف في اختبار اختراق تطبيقات الويب وصيد الثغرات.

---

## 📚 1. الكتب المرجعية الكبرى (Core Books)

1. **The Web Application Hacker's Handbook: Finding and Exploiting Security Flaws (2nd Edition)**
   * *المؤلفون:* Dafydd Stuttard & Marcus Pinto (مؤسسو شركة PortSwigger ومبتكرو أداة Burp Suite).
   * *الأهمية:* يُعد "الإنجيل المرجعي" لأمان تطبيقات الويب؛ يشرح بالتفصيل الممل كافة البروتوكولات والآليات الداخلية لثغرات الويب.
2. **Bug Bounty Bootcamp: The Guide to Finding and Reporting Web Vulnerabilities**
   * *المؤلفة:* Vickie Li.
   * *الأهمية:* كتاب تطبيقي حديث يشرح كيفية صيد الثغرات وكتابة التقارير وكسب المكافآت على منصات HackerOne و Bugcrowd.
3. **Real-World Bug Hunting: A Field Guide to Web Hacking**
   * *المؤلف:* Peter Yaworski.
   * *الأهمية:* استعراض وتحليل لعشرات الثغرات الحقيقية التي تم اكتشافها في شركات كبرى مثل تويتر وفيسبوك وجوجل.
4. **Web Security for Developers**
   * *المؤلف:* Malcolm McDonald.
   * *الأهمية:* مرجع ممتاز لفهم الثغرات من منظور المبرمج وكيفية بناء ترقيعات دفاعية متينة.

## 🎓 2. الشهادات المهنية الموصى بها (Certifications)

* **Burp Suite Certified Practitioner (BSCP):**
  * *الجهة المانحة:* PortSwigger الرسمية.
  * *الطبيعة:* اختبار عملي شاق بنسبة 100% مدته 4 ساعات، يختبر قدرتك على استغلال سلسلة معقدة من الثغرات المتقدمة حصرياً باستخدام أداة Burp Suite Professional. تُعد من أقوى وأصدق الشهادات التخصصية في السوق حالياً.
* **eLearnSecurity Certified Web App Penetration Tester (eWPT / eWPTX):**
  * *الجهة المانحة:* INE Security.
  * *الطبيعة:* اختبار عملي واقعي لفحص تطبيق ويب متكامل وكتابة تقرير احترافي للعميل.
* **Offensive Security Web Expert (OSWE / WEB-300):**
  * *الجهة المانحة:* OffSec.
  * *الطبيعة:* شهادة متقدمة تركز على مراجعة الكود المصدري (White-box Code Review) وبناء هجمات الاستغلال المتقدمة في الويب.

## 🧪 3. المعامل والمنصات التدريبية المعتمدة (Practice Labs)

1. **[PortSwigger Web Security Academy](https://portswigger.net/web-security):**
   * المنصة التعليمية المجانية الأولى عالمياً؛ تحتوي على مئات المعامل التفاعلية المصممة لمحاكاة سيناريوهات الويب الواقعية، وتتكامل بسلاسة تامة مع أداة Burp Suite.
2. **[TryHackMe - Web Fundamentals & Burp Rooms](https://tryhackme.com):**
   * غرف تفاعلية ممتازة للمبتدئين تتيح ممارسة اعتراض الطلبات وتشغيل أدوات Intruder و Repeater خطوة بخطوة.
3. **[HackTheBox](https://www.hackthebox.com):**
   * تحديات أسبوعية وأجهزة افتراضية (Machines) متطورة تحاكي خوادم وشبكات شركات حقيقية.

---

## 🛠️ 4. مستودعات الأدوات والقواميس المساندة (Toolkits & Wordlists)

* **[SecLists (Daniel Miessler)](https://github.com/danielmiessler/SecLists):**
  * أضخم وأشهر مستودع للقواميس وقوائم التخمين (Wordlists) في العالم لمسارات الروابط، وأسماء المستخدمين، وكلمات السر، وحمولات الـ Fuzzing.
* **[PayloadsAllTheThings](https://github.com/swisskyrepo/PayloadsAllTheThings):**
  * المستودع الشامل لحمولات الاستغلال الجاهزة لكافة أنواع الثغرات (SQLi, XSS, SSRF, XXE, Deserialization, SSTI).
* **[ffuf (Fast Web Fuzzer)](https://github.com/ffuf/ffuf):**
  * أداة التخمين السريعة المكتوبة بلغة Go؛ البديل المثالي لأداة Intruder في النسخة المجانية للتعامل مع القواميس الضخمة.
* **[ProjectDiscovery Interactsh](https://github.com/projectdiscovery/interactsh):**
  * البديل المجاني ومفتوح المصدر لخادم Burp Collaborator لصيد تفاعلات الـ Out-of-Band (OAST).
